## 一、截图取证：拿到了决定性基准

### 1.1 窗口截图可行，点击驱动不可行（已定位根因）

| 能力 | 结果 | 说明 |
|---|---|---|
| 窗口截图 | ✅ 可行 | `ImageGrab` + `ctypes` 取窗口矩形，成功抓到中文版完整界面 |
| 点击/键盘驱动 | ❌ **不可行** | **WorkBuddy 两个进程都以管理员权限运行（`TokenIsElevated = True`，实测）**，非提权进程的合成输入被 UIPI 静默丢弃。坐标已用十字准星校验确认无误，点击仍无响应 |

> 取证脚本已归仓：`scripts/_win_list.py`（列窗口）、`scripts/_win_shot.py`（还原+置顶+截图）、`scripts/_win_shot_seq.py`（点击序列，受 UIPI 限制不可用）。

### 1.2 关键发现：WorkBuddy 左侧栏是**复合结构**

实时截图（`docs/_shots/wb-live-20260924/01-对话态-完整左侧栏.png`）显示，左侧栏自下而上为：

```
① 品牌区    WorkBuddy 5.6.2 + 「发现应用」
② 主导航 7 项  新建任务 / 助理 / 项目 / 专家·技能·连接器 / 定时任务 / 资料库 / 更多
③ 任务 (34) ∨  ← 会话列表就在这个分组里（含「查看更多 (29)」）
④ 空间 (10) ∨  ← 空间/资料库分组（HR有关AI ∨ + 子项）
⑤ 底部用户区  Steven + 图标
```

**这修正了我上一轮的推断**：会话列表不是独立面板，而是左栏内的「任务」分组。

另发现：**本机有两个 WorkBuddy 客户端**——`WorkBuddy.exe`（中文版 5.6.2，左侧 7 项）与 `WorkBuddyAI.exe`（英文版 5.5.2，左侧仅 5 项，无「项目」「资料库」）。阿长要的是**中文版**，基准已按中文版取。
