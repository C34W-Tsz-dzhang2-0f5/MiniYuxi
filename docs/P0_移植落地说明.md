## 四、怎么用

1. 双击 `start_miniyuxi.bat` 起服务（127.0.0.1:8801）。
2. 合同台账：POST `/api/labor/contracts` 录入，POST `/api/labor/sync` 立即扫描，GET `/api/labor/dashboard` 看预警。
   每日 08:00 会自动跑一次，无需人工触发。
3. 薪酬：POST `/api/salary/records` 录明细，GET `/api/salary/summary?month=2026-09` 看汇总，POST `/api/salary/qa` 问"实发工资怎么算"。
4. 技能：UI 左侧「技能」抽屉现在能点选 `skills/` 下的 45 个文件夹 skill（标「【文件夹技能】」），选中后其 SKILL.md 正文会注入对话。

## 五、遗留与风险

- 🟡 **绩效、培训模块双方都没有**——仍是共同空白，需另起设计。
- 🟡 **简历规则引擎词典偏窄**：`SKILL_LEXICON` 仅覆盖软件工程师/销售/HR/产品经理 4 类，其它岗位需补词典。
- 🟡 **规则评分是相对分**：未识别维度不计入分母（信息缺失不惩罚），字段极稀疏的简历可能虚高——人工复核时看 `fields` 完整度，或传 `strict=True` 用保守口径。
- 🟢 运行时表不入库；`data/` 与调试备份 `data/miniyuxi.db.bak_smoke_*` 均已被 gitignore。
- 🟢 第14条提示为规则预警，**不构成法律意见**，另有第39条、第40条第1/2项除外情形。
