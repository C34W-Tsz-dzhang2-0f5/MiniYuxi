## 四、⚠️ 必须先定的前提问题

**照搬 7 项导航 = 砍掉 MiniYuxi 自有 5 个模块的入口**：HRM人事、流程、成本管理、管理、岗位工作台（另有「导入」「模型切换」）。
这些模块**在 WorkBuddy 桌面端导航里根本不存在**（asar 中 `岗位工作台`/`成本管理` 命中数为 **0**）。

→ 阿长要的「完全一致」与「保留自有模块」存在冲突，必须二选一或给出安置方案。
