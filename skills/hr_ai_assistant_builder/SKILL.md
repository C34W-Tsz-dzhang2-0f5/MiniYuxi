# HR AI 助手构建器（模块化 · 开源替代北森）

## 何时使用
用户要为 HR 某个职能模块（招聘、绩效、薪酬福利、培训发展、劳动关系、人力资源规划）搭建 AI 应用 / 智能体，希望**私有化、零授权费、可落地交付**，而非购买北森等商业 HR SaaS。本技能提供经实战验证的整套工作流。

## 核心架构（对齐《HR智能体一体化平台目标任务书》+《AI应用基座与平台总体设计》）
- **1+N+X**：1 个底座（模型网关 + RAG + 合规护栏）+ N 个 HR Agent（按模块）+ X 个 MCP 工具连接器。
- **四层 + 三横**：基础层（模型/网关/LiteLLM Provider）/ 数据层（RAG+向量+BM25）/ 能力层（Agent编排）/ 应用层（企微+工作台）；横向贯穿 安全合规 + 监控运维 + 知识治理。
- **模型网关**：统一 OpenAI 兼容接口，支持本地 Mock 回退（不填 API Key 也能跑 Demo）。
- **编排**：确定性状态机优先于自由 Agent（见 `statemachine.py` 范式），关键节点 HITL（人工确认），禁用自动批准（发 Offer / 审批提交）。

## 合规红线（必须内置，不可绕过）
1. **数据脱敏**：工资/个税/合同/争议证据等敏感字段禁止外发；私域数据最小化授权、私有化部署、不出企微/内网隔离环境。
2. **用工混同校验**：跨主体签约（母子公司，如中国香港/中国台湾/中国澳门相关或集团内多法人）须校验签约主体与社保/用工主体一致，呼应劳动争议混同用工风险。
3. **算法公平**：简历初筛/绩效评分禁止以性别、地域、年龄等非业务因子做决策依据（依据《个人信息保护法》第24条自动化决策条款）。
4. **MCP 安全**：网关前置；禁用自动批准；PKCE；仅用认证 MCP；WebFetch 重定向须二次确认。82% 路径遍历/67% 代码注入风险 → 网关统一拦截。
5. **金融/涨跌约定**：若涉及薪酬涨跌可视化，涨=红、跌=绿（中国 convention），¥ 为默认货币。

## 标准化交付物（映射模板 01-11）
| 模板章 | 产出 |
|---|---|
| 01 核心业务清单 | 模块业务项清单（名称/描述/工具/日均） |
| 02 业务痛点 | 痛点（类型/当前方式/影响程度） |
| 03 核心SOP | 每 SOP 5 步：负责人/输入/工具/输出/判断条件/AI可能性 |
| 04 Top3软件 | 开源 vs 商业对比（已规避北森，强调零授权/私有化） |
| 05 AI场景 | 每个场景：目标/数据/现状/AI做法/收益/风险 |
| 06 流程优化10→2 | 改造前后对比 + 效果指标 |
| 07 企微协同 | 6 问（场景/系统/数据/权限/安全边界/研发评估） |
| 08 选型建议 | 开源栈清单 + 拒绝北森理由 |
| 09 实施计划 | 30/60/90 天 P0-P3 路线图 |
| 10 预期收益 | 量化指标 + ROI |
| 验收清单 | 逐条 ✓ 自查 |

## 构建步骤（参考 `build_all_v2.py` 范式）
1. **调研**：读取既有模板/手册/SOP/PDF，提取模块真实流程（必做，不要凭空编造）。
2. **设计**：按 1+N+X + 模块状态机 + 合规护栏定方案。
3. **脚手架**：新建项目目录 + `src/`（llm/prompt/compliance/rag/resume/statemachine/mcp_tools/wecom/dashboard）+ `docs/` + `deliverables/`。
   - `llm.py`：OpenAI 兼容 Provider，支持 Mock 回退。
   - `compliance.py`：脱敏/公平/混同/涨跌/货币 统一校验函数。
   - `rag.py`：读取业务手册 → 分块 → BM25+TF-IDF 混合检索 + 引用溯源（不强制向量库，纯标准库可跑）。
   - `statemachine.py`：阶段流转 + 审批路由 + 超时升级。
   - `mcp_tools.py`：只读优先，发令类动作 HITL 闸门。
   - `wecom.py`：企微协同，敏感字段脱敏。
   - `dashboard.py`：指标 + 双周报 + 异常预警（红涨绿跌）。
   - `app.py`：Streamlit 工作台；`cli_demo.py`：离线端到端自检。
4. **对齐模板**：将 01-11 内容落到交付文档，保持原模板文字零改动（仅填空白输入格）。
5. **交付**：`deliverables/` 输出状态机 JSON + 审批路由 JSON；`present_files` 预览。

## ⚠️ 安装依赖（关键坑，务必先看 win-python-sandbox-install 技能）
- 沙箱内**不要** `pip install --upgrade pip`（会触发删除 pip.exe 安全拦截导致 venv 损坏）。
- 用托管 Python 自带包（openpyxl 已有）可直接跑离线版；需要 Streamlit 时：**新建独立 venv → 清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple` 直接装**，不升级 pip。
- 不用 `rm -rf` 删 venv；换新目录名重建。

## 验证
- `python -m src.cli_demo` 离线跑通（RAG 加载块数、初筛/面试/状态机/MCP/合规/看板）。
- `python -m py_compile src/*.py` 全编译通过。
- 生成交付物后用 present_files 打开预览。

## 横向复制
绩效/薪酬/培训/劳动关系版本复用同一架构：仅替换 `rag.py` 知识源、`statemachine.py` 阶段定义、`compliance.py` 的关注点（薪酬强调敏感数据、劳动关系强调混同用工）。强制：凡涉个人信息/薪酬/审批，必须联动合规模块。

## 已知边界
- 本技能不涵盖 MCP server 真实配置（用 mcp.json），不涵盖企微真实回调（需 `agent-browser` 或企微凭证）。
- 用户级技能；若团队共享需求可移到项目级 `.workbuddy/skills/`。
