# AI简历初筛专家

## 功能简介
一款专为HR招聘岗位设计的AI招聘助手工具。针对传统简历筛选中人工效率低、标准不统一、优秀人才容易漏过的痛点，实现简历与岗位JD智能匹配、匹配度量化评分、候选人亮点/风险点自动提取三大核心能力。

支持自定义岗位胜任力模型、批量处理上百份简历、自动生成候选人对比分析报告，帮助HR将简历筛选效率提升90%以上，将优秀人才识别率提升40%。适用于校园招聘、社会招聘批量简历处理、核心岗位精准招聘等场景。

## 使用方法

### 前置准备
1. 准备岗位JD（职位描述）文档
2. 收集所有候选人的简历文件（支持PDF/Word/图片格式）
3. 明确岗位核心要求和筛选标准

### 操作步骤
1. **创建招聘项目** — 录入岗位基本信息，上传或粘贴岗位JD描述，设置筛选门槛
2. **批量导入简历** — 批量上传候选人简历文件，系统自动解析并提取结构化信息
3. **配置匹配规则** — 设置各筛选维度权重，自定义关键词库，配置加分/减分规则
4. **启动智能筛选** — 系统自动进行简历-JD匹配计算，生成匹配度评分和排名
5. **结果审核与导出** — 查看排名和详细分析报告，一键导出初筛通过候选人名单

## 使用示例
```
上传10份销售经理岗位候选人的简历，JD要求：5年以上销售经验、带过团队、熟悉CRM系统。
系统自动匹配后，输出排名前三的候选人，并标注各自的亮点和风险点，节省1小时人工筛选时间。
```
